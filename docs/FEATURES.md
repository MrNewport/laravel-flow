# Native Flow feature index

This index covers the current native public surface. The engine works without Workflow/Fields. Guide links provide behavior, errors and application context; [executable review](../examples/review.php) and [documentation regression test](../tests/Feature/DocumentationExamplesTest.php) cover the independent parallel lifecycle.

| Surface / signature → return | Contract / failures | Guide and example |
| --- | --- | --- |
| `FlowManager::startFlow(string $stepId, $entity): FlowInstance` | Saved same-connection Eloquent or getKey object, configured identity type; invalid → InvalidArgumentException; unknown definition → ModelNotFoundException. Transactional initial assignments; no start event. | [Lifecycle](HANDBOOK.md#define-start-and-complete-a-flow), [identity](HANDBOOK.md#subject-identity), [approval](RECIPES.md#transactional-purchase-approval) |
| `FlowManager::actionStep(FlowInstanceStep, string $action): array` | Entries are new steps/null terminal; persisted completed → LogicException; undefined/overbudget action → InvalidArgumentException; missing target → ModelNotFoundException; all writes atomic. | [Lifecycle](HANDBOOK.md#define-start-and-complete-a-flow), [parallel](HANDBOOK.md#transactions-concurrency-and-parallel-branches) |
| `FlowManager::reassignStep(FlowInstanceStep, $currentUser, array $newAssignees, $subject = null): bool` | False for no strategy/denied; pending-state lock; optional subject binding; invalid ownership/list → InvalidArgumentException; completed → LogicException. | [Assignments](HANDBOOK.md#assignment-strategies-and-exact-identities) |
| `Flowable::flowInstance(): HasOne` | Alias/FQCN-compatible subject relation; use explicit instances for multiple runs. | [Trait](HANDBOOK.md#flowable-trait) |
